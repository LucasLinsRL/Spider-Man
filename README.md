# 🕷️ Site Spider-Man

Projeto desenvolvido como **trabalho acadêmico** durante o **ensino médio técnico na ETEC**, no ano de 2022.

O site tem como objetivo apresentar o universo do Homem-Aranha, abordando personagens, filmes, variantes e uma área de resenha para interação dos usuários.

---

## 🎯 Objetivo do Projeto
Aplicar conceitos fundamentais de **desenvolvimento web**, como estruturação de páginas, estilização com CSS e organização de conteúdo, em um projeto temático e visualmente atrativo.

---

## 🛠️ Tecnologias Utilizadas
- HTML5  
- CSS3  
- JavaScript  
- Font Awesome  
- Google Fonts  

---

## 📱 Responsividade
O projeto foi inicialmente desenvolvido com foco em **desktop**.  
Posteriormente, recebeu **ajustes de responsividade utilizando apenas CSS**, visando melhorar a experiência em dispositivos móveis e tablets, respeitando a estrutura original do site.
